## Projects

### 1. Saber 11 Score Prediction — Machine Learning

A supervised machine learning project focused on predicting students' global scores in Colombia's Saber 11 standardized examination using family, socioeconomic, and school-related characteristics.

**Objectives:**
- Explore relationships between students' backgrounds and academic performance.
- Clean and preprocess real-world educational data.
- Build and compare regression models.
- Evaluate predictive performance using multiple metrics.
- Identify the features that contribute most to model predictions.

**Models implemented:**
- Linear Regression
- Random Forest Regressor
- Histogram-Based Gradient Boosting Regressor

**Evaluation metrics:**
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- Coefficient of Determination (R²)
- Cross-validation

The dataset corresponds to the 2020-2 Saber 11 examination period and is sourced from Colombia's open government data platform.

This project demonstrates practical experience with supervised learning, regression, preprocessing pipelines, model evaluation, and feature importance analysis.

## Data Science Workflow

My projects generally follow these steps:

1. **Problem Definition:** Identify the question or problem to be addressed.
2. **Data Collection:** Obtain datasets from available sources.
3. **Data Cleaning:** Handle missing values, duplicates, and inconsistencies.
4. **Exploratory Data Analysis:** Investigate distributions, relationships, and patterns.
5. **Feature Engineering and Preprocessing:** Prepare the data for analysis or modeling.
6. **Model Development:** Train and compare appropriate machine learning algorithms when applicable.
7. **Model Evaluation:** Assess results using relevant metrics and validation techniques.
8. **Interpretation:** Explain the findings, limitations, and potential applications.

Not every project requires every step; the workflow is adapted to the problem being solved.

Datasets are obtained from public sources or educational exercises whenever applicable. Individual projects should identify their data sources and explain any relevant assumptions or limitations.

For example, the Saber 11 prediction project uses data from a specific examination period. Its findings should not automatically be generalized to other years, and predictive relationships should not be interpreted as proof of causation.
